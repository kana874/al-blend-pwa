# Al 配合計算 PWA Ver.1.1.0

純Al～高純度Alを母材とした、Cu / Si / Ti等の微量添加向け配合支援PWAです。

## Ver.1.1.0 新機能

- 結果サマリーに「添加量単位」セレクタを追加しました。
- 総添加量と複数元素時の各元素添加量を `自動 / mg / g / kg / t` から切り替えられます。
- 選択した表示単位はlocalStorageへ保存し、次回起動時にも維持します。
- 天秤分解能を選択した表示単位へ換算し、その分解能に対応する小数桁で表示します。
- 添加後総重量は従来仕様どおり、溶湯量と同じ単位で表示します。

## 実装済み

- 配合計算（複数元素、共通の最終総重量を連立で考慮、元素別添加量サマリー）
- 添加確認
- 歩留まり手動入力 / 逆算 / 実績保存 / 統計
- 希釈計算
- 純元素・母合金の添加材マスタ（既存データ編集・CSV出力）
- 天秤マスタ（g / kg、既存データ編集・CSV出力）、四捨五入 / 切上げ / 切捨て、上下候補
- wt% / ppm / ppb、mg / g / kg / t
- 表示桁数設定（内部精度とは分離）
- 結果サマリーの添加量表示単位切替（自動 / mg / g / kg / t）
- 計算成功時に自動保存されるIndexedDB履歴、localStorage設定
- 配合プリセット（溶湯量と現在濃度を除外して保存・再利用）
- JSONバックアップ / 復元、UTF-8 BOM付きCSV
- オフラインヘルプ、初回チュートリアル
- manifest / Service WorkerによるPWA・オフラインキャッシュ
- 依存CDNなし
- Node / ブラウザ向け計算エンジンテスト

## Windowsで起動

1. `start_local_server.bat` をダブルクリックします。
2. `http://localhost:8080` が開きます。
3. Edge / Chromeの「アプリをインストール」からPWAとして追加できます。
4. 一度キャッシュされた後は主要機能をオフラインで利用できます。

`index.html`を直接開いて計算UIを見ることもできますが、Service Worker / PWAインストールはHTTP(S)またはlocalhostでの起動が必要です。

## テスト

Node.jsがある場合、フォルダで次を実行します。

```bash
npm test
```

または `tests/test.html` をブラウザで開きます。

## 保存データ

- localStorage: 表示設定、最後の画面、チュートリアル既読
- IndexedDB: 添加材、天秤、歩留まり実績、計算履歴、配合プリセット等

ブラウザデータの消去に備え、「設定・データ」からJSONバックアップを定期的に保存してください。


## Ver.1.0.4 追加仕様
- 天秤マスタの分解能単位は g / kg から選択できます。
- 配合・添加確認・歩留まりの元素選択肢は、有効な添加材マスタの主元素から重複を除いて自動生成されます。
- 添加材マスタの「メーカー」欄は「備考」欄に変更しました。


## Ver.1.0.7 追加仕様

- 配合計算、添加確認、歩留まり逆算、希釈計算は、計算成功時に計算履歴へ自動保存されます。
- 天秤マスタ・添加材マスタは、登録済みデータを「編集」から更新できます。
- 天秤マスタ・添加材マスタは、それぞれUTF-8 BOM付きCSVで外部出力できます。
- 配合プリセットを保存・読み込みできます。プリセットには目標値、添加材、歩留まり、単位、天秤、丸め方式等を保存し、読み込み時は「溶湯量」と各元素の「現在濃度」だけ空欄にします。
- 複数元素の配合計算では、結果サマリーに元素ごとの推奨添加量を表示します。

## Ver.1.0.7 修正
- 2元素以上の配合では、結果サマリーに元素別の推奨添加量を表示します。
- 計算履歴は正常な計算完了時に自動保存され、履歴一覧も即時更新されます。
