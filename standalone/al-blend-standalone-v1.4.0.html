アプリの目的

純Al～高純度Alを母材とし、Cu・Si・Ti等を添加する配合作業を支援します。配合計算、添加確認、歩留まり逆算、希釈計算を1つのPWAで扱います。

基本的な配合計算

  1. 溶湯量と天秤を設定します。
  2. 元素ごとに現在濃度と目標濃度を入力します。
  3. 添加材と目的元素含有率、歩留まりを設定します。
  4. 「計算」で理論添加量、推奨秤量値、丸め後予想濃度を確認します。

ppm / wt% / ppb

内部ではすべて質量分率に変換します。1 wt% = 10,000 ppm = 10,000,000 ppbです。表示単位が異なっても同じ質量基準として計算します。

純元素と母合金

純元素は、使用する添加材の分析値または保証純度に応じて目的元素含有率を登録します。母合金はAl-5TiならTi 5.000 wt%として登録します。Ver.1.0では主目的元素のみを計算対象とし、副次成分の連成はVer.2.0対象です。

添加歩留まり

添加した目的元素のうち、計算上溶湯中に有効残留した割合です。100%では全量有効とみなします。逆算値が0%未満または100%超でも自動補正はしません。

天秤分解能と秤量丸め

理論値とは別に、天秤分解能に基づく下側・四捨五入・上側の秤量候補を再計算します。天秤マスタでは分解能の単位をgまたはkgで登録できます。表示の丸めは内部計算精度に影響しません。

希釈計算

現在濃度が目標濃度を上回った場合、希釈用Alの目的元素濃度も考慮して必要追加量を求めます。希釈材濃度は目標濃度より低い必要があります。

計算式（標準モデルA）

C1 = (M*C0 + x*P*Y) / (M+x)

x = M*(Ct-C0) / (P*Y-Ct)

Y = [C1*(M+x) - M*C0] / (x*P)

M: 初期溶湯重量、C0: 初期濃度、Ct: 目標濃度、C1: 添加後濃度、P: 添加材中目的元素質量分率、Y: 歩留まり、x: 添加材重量。

データ保存とバックアップ

設定はlocalStorage、添加材・天秤・歩留まり実績・計算履歴・配合プリセットはIndexedDBに保存します。計算履歴は計算成功時に自動保存されます。ブラウザデータ消去に備え、定期的なJSONバックアップを推奨します。

よくある質問

サーバーは必要ですか？

計算自体には不要です。PWAとしてインストールする場合は初回配布にHTTPSまたはlocalhostが必要です。インストール後はオフラインで動作します。

歩留まりが100%を超えました。

分析値、溶湯重量、実添加量、サンプリングばらつき等を確認してください。値は自動的に100%へ補正しません。

複数元素を同時に計算できますか？

できます。Ver.1.0では各添加材が共通の最終総重量を増加させる効果まで連立で考慮します。
