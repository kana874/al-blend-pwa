# リリースノート

## Ver.1.0.0 — 2026-08-21

初回実装。

### 計算
- 標準モデルAによる必要添加量計算
- 添加後濃度確認
- 添加歩留まり逆算
- 高純度Alによる希釈計算
- 複数元素の総添加重量連立補正
- wt% / ppm / ppb、mg / g / kg / t変換
- 高精度10進演算
- 天秤分解能に基づく秤量候補

### データ
- 添加材・天秤マスタ
- 歩留まり実績と採用/除外
- 歩留まり統計（件数、平均、中央値、最小、最大、標準偏差）
- 計算履歴
- JSONバックアップ/復元
- CSV出力

### PWA / UX
- PCサイドバー / スマートフォン下部ナビ
- オフラインヘルプ
- 初回チュートリアル
- Service Worker / manifest
- 初期サンプル添加材・天秤

### Ver.1.0の境界
- 複合母合金の副次成分連成計算はVer.2.0対象
- 製品規格判定はVer.2.0対象
- クラウド同期・ERP/MES連携は対象外
